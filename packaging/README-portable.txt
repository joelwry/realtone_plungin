RealTone Studio - portable package
==================================

No installation is needed for the standalone application:

  RealTone Studio.exe   run it from any folder
  realtone-cli.exe      command line renderer
  RealTone Studio.vst3\ the VST3 plug-in bundle (a folder)

To use the plug-in in a DAW, copy the whole "RealTone Studio.vst3" folder to
  C:\Program Files\Common Files\VST3
(this needs administrator rights), or to any VST3 folder your DAW scans.

The program keeps its settings, presets and downloaded sample libraries in
  %LOCALAPPDATA%\RealToneStudio
so deleting this folder never removes your data.

See docs\USER_GUIDE.md and docs\INSTALL_AND_TROUBLESHOOTING.md.
